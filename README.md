# Atualizações em Seleção Genômica

Seja bem-vindo(a)! 

Este repositório contém o material referente ao curso "Atualizações em Seleção Genômica", ministrado por mim e organizado pelo GVENCK. O repositório possui a seguinte estrutura:

```
GS_GVENCK/
├── Data/
│   ├── G2F.RDS                         # Médias ajustadas de 211 experimentos instalados no contexto do projeto "Genomes to Fields"
│   ├── markers.vcf                     # Dados brutos dos marcadores moleculares (SNPs)
│   ├── mrk_filtered.RDS                # Dados filtrados e recodificados dos marcadores moleculares
│   ├── Soil.csv                        # Dados ambientais de características relacionadas ao solo, coletadas *in loco*
│   └── weather_seasons.csv             # Dados climáticos coletados a partir de estações meteorológicas próximas
├── Presentations/
│   ├── day1.html                       # Apresentação do primeiro dia de curso
│   ├── day2.html                       # Apresentação do segundo dia de curso
│   └── day3.html                       # Apresentação do terceiro dia de curso
├── Saves/
│   ├── RDA                             # Pasta com arquivos de salvamento do R com resultados dos modelos já rodados
│   └── dat                             # Pasta com arquivos .dat com as posterioris construídas pelo BGLR
├── README.md                           # Esta documentação
├── LICENSE                             # Licença de uso
├── SG_GVENCK.Rproj                     # Arquivo do projeto R
└── .gitignore                          # Arquivos excluídos do controle de versão
```
